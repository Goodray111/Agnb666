How I chose them

A good next project is small enough to finish and strange enough to be interesting. These are the four questions I used to rank the list.

  1. Can I finish it in a weekend? If not, it goes to Someday.
  2. Does it teach me one thing properly? One new idea per project is enough.
  3. Would I use it afterwards? A tool I need is easier to finish than a demo.
  4. Is it small enough to show? If the first screen needs a paragraph to explain, it is too big.

What I would start with

The tide clock. It needs a real API, real dates and a layout that survives a narrow phone screen — three things the course covered and I have not used together yet.
