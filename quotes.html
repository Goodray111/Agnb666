Why a quotes page

The brief asked for fifteen quotes. It is a good exercise for one reason: it is a list that has to be readable, searchable and pleasant, without a database or a framework. Everything here is in the HTML.

Written for the page

Each quote is a blockquote with a cite and a source line. The markup carries the meaning; the styling just helps.

Filtered in the browser

The search box and the theme chips filter the same elements. No network request, no reload, and the count updates as you type.

One random quote

The button picks from the same list and writes the result into the card above. If JavaScript is off, all eighteen are still there to read.
