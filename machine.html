04 · Machine

A machine that does nothing, on purpose

The useless machine is a box with one switch. Turn the switch on and a hand comes out and turns it off. It is the most honest machine ever built. Below it is a small game: bugs keep appearing, and you have to catch them.

The useless machine

One switch, one job

Click the switch. The lid opens, a hand reaches out, and the machine switches itself off again. That is the whole machine — and that is the point.

Built with a checkbox-like button, a CSS transition and about forty lines of JavaScript. It respects prefers-reduced-motion: no hand, no delay, just the state change.

How it works

Two toys, the same three ideas: a state, a function that changes it, and a page that shows the change.

The machine

A boolean, a button, and a timeout. Turning the machine on starts a sequence; the hand comes out, the switch flips back, the lid closes.

The game

One bug element is moved to a random spot every time it is caught. A single interval runs the clock. Stopping clears both timers.

Care

Buttons are real buttons, the field is focusable, and the score is announced. Motion is optional, never required to understand the page.
